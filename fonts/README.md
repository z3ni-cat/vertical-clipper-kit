# Font

Paket ini dirancang memakai font **Anton** (SIL Open Font License 1.1).

File biner font tidak disertakan di repo GitHub ini (keterbatasan unggahan),
silakan unduh sendiri dari Google Fonts:

- https://fonts.google.com/specimen/Anton (tombol "Download family")

Lalu simpan berkas `Anton-Regular.ttf` sebagai `fonts/Anton.ttf` di folder ini
(atau arahkan `font_display` di `config.py` ke lokasi font pilihanmu —
font display tebal lain seperti Archivo Black atau Titan One juga cocok).

Lisensi font: lihat `FONT_LICENSE.md`.
