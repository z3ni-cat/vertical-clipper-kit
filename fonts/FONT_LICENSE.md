# Catatan Lisensi Font

## Anton (`Anton.ttf`)

- Desainer: Vernon Adams.
- Lisensi: **SIL Open Font License 1.1 (OFL)** — font boleh dipakai,
  disalin, dan didistribusikan ulang secara bebas, termasuk di dalam
  paket seperti ini, selama catatan lisensinya disertakan.
- Teks lengkap OFL 1.1: https://openfontlicense.org/open-font-license-official-text/

Ringkasan OFL (bukan pengganti teks resmi): font boleh digunakan untuk
keperluan pribadi maupun komersial, boleh dimodifikasi dan dibundel
dengan perangkat lunak; font itu sendiri tidak boleh dijual terpisah;
karya turunan font harus tetap berlisensi OFL.

Font bawaan sistem (mis. untuk footer bila `FOOTER_FONT` dikosongkan)
tidak didistribusikan dalam paket ini.
